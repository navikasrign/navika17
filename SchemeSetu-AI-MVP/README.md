# SchemeSetu AI MVP

SIH26092 prototype by Team INNOVEXA.

## What this MVP demonstrates
- Profile Intelligence through a structured entrepreneur profile
- Explainable scheme matching with sample rules and ranking
- Document readiness checklist
- Name-variation similarity demo for multilingual/transliteration-style inconsistencies
- DPR draft generation from business inputs
- Benefit compatibility demo
- Application readiness score
- Trust-layer concepts: consent, confidence scores, user verification, versioned scheme rules

## Run locally
Open `index.html` directly in a browser, or serve this folder using any static web server.

## Important prototype note
This is a demonstration MVP with sample scheme data and simulated document-intelligence logic. It does not make official government eligibility, identity, financial, or sanction decisions. Production deployment would require authoritative scheme-rule ingestion, validated OCR/Indic NLP pipelines, security controls, and official integrations.
